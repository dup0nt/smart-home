# Smart home architecture

This repository has two deliberately separate documentation areas:

- [`spec/`](spec/) — shareable, house-agnostic architecture and design decisions.
- `home-spec/` — local installation notes, purchasing, room layout, electrical survey information, and other private material. It is ignored by Git.

The public specification is safe to publish only after reviewing the commit. Do not add addresses, floor plans, device names, Wi-Fi details, API tokens, backups, recordings, or personal conversation data.
